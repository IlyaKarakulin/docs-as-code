# API

API предоставляет доступ к функциям сервиса «Анализатор отзывов».

## Основные операции

- `POST /analysis` — отправить отзыв и определить его тональность;
- `GET /analysis/{id}` — получить сохранённый результат анализа;
- `GET /models` — получить список доступных моделей.

## Ответ анализа

Результат содержит тональность (`positive`, `neutral`, `negative`), уверенность модели
(`confidence`, от 0 до 1), признак `needsReview`, версию модели и время анализа.

## Ошибки

Ошибки возвращаются в формате `{ "code": "...", "message": "..." }`:
`400` — некорректный текст, `404` — результат не найден,
`500` — внутренняя ошибка, `503` — модель недоступна.

## Спецификация

Полное описание API находится в файле [`openapi.yaml`](openapi.yaml).
Интерактивная версия — на странице [Swagger UI](swagger.md).
