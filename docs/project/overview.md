# Анализатор отзывов

Сервис автоматически определяет тональность текстового отзыва о товаре или услуге:
**положительная**, **нейтральная** или **отрицательная**. Для классификации используется
ML-модель обработки естественного языка, дообученная на размеченных отзывах на русском языке.

Сервис помогает быстро оценить настроение клиентов, не читая вручную сотни отзывов,
и своевременно заметить негативные отзывы, требующие реакции.

Основные пользователи:

- пользователь (автор отзыва или сотрудник, который загружает отзывы);
- аналитик (просматривает статистику по тональности отзывов).

Основные функции:

- отправка отзыва на анализ;
- определение тональности отзыва;
- просмотр результата и статистики по тональности.

## Комплект документации

1. **Описание проекта** — для всех участников и новых членов команды: даёт общее представление о назначении и границах сервиса.
2. **Требования (User Stories, Use Case)** — для аналитиков, разработчиков и тестировщиков: фиксирует, что должен уметь сервис и как проверить результат.
3. **Архитектура системы** — для разработчиков и архитекторов: описывает компоненты, их связи и потоки данных.
4. **Документация API** — для разработчиков-интеграторов: показывает, как отправить отзыв и получить тональность по HTTP.
5. **Документация ML-модели** — для ML-инженеров и аналитиков: описывает данные, метрики качества, ограничения и способ переобучения модели.
6. **Руководство пользователя** — для аналитиков и пользователей: объясняет, как пользоваться сервисом и читать результаты.
7. **Руководство по развёртыванию** — для DevOps-инженеров: описывает установку, настройку и запуск сервиса.
