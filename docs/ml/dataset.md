# Data Sheet

## Общая информация

**Название датасета:**
RuReviews — An Automatically Annotated Sentiment Analysis Dataset for Product Reviews in Russian.

**Источник:**
[GitHub: sismetanin/rureviews](https://github.com/sismetanin/rureviews).
Авторы — Sergey Smetanin, Michail Komarov. Датасет описан в статье
«Sentiment Analysis of Product Reviews in Russian using Convolutional Neural Networks»
(IEEE CBI 2019).

**Назначение:**
Обучение и оценка моделей анализа тональности отзывов о товарах на русском языке.
Именно на этом датасете обучена выбранная модель
`blanchefort/rubert-base-cased-sentiment-rurewiews` (см. [Model Card](model-card.md)).

**Лицензия:**
Apache License 2.0 (указана в репозитории датасета).

## Состав данных

**Объём:**
Исходно собрано около 821 тыс. автоматически размеченных отзывов. В опубликованном
сбалансированном файле `women-clothing-accessories.3-class.balanced.csv` (около 21 МБ)
90 000 отзывов, по 30 000 на каждый класс.

**Тип данных:**
Текст (отзывы покупателей на русском языке) и метка класса. Формат — TSV
(разделитель — табуляция).

По нашему подсчёту по файлу датасета: медианная длина отзыва — 91 символ,
средняя — около 130 символов, максимальная — 1000 символов.
Около 5 тыс. отзывов короче 20 символов.

**Основные поля / признаки:**

| Поле | Описание |
|---|---|
| `review` | Текст отзыва |
| `sentiment` | Тональность: `positive`, `neautral` (так в исходном файле), `negative` |

## Получение данных

По описанию авторов, отзывы собраны с популярных товаров крупного российского
интернет-магазина. Название магазина в README не указано. Брались отзывы только из одной
категории — «Женская одежда и аксессуары», потому что одни и те же слова в разных
категориях могут иметь разную тональность.

Метки получены автоматически из пользовательской оценки по 5-балльной шкале, вручную
отзывы не размечались.

Согласие авторов отзывов на использование данных и анонимизация: не указано.

## Предобработка

По описанию авторов:

- 5-балльная шкала сведена к 3 классам: оценки 1–2 → `negative`, 4–5 → `positive`,
  3 → `neutral`. В README написано «3 and 5», но из контекста понятно, что положительный
  класс — это 4 и 5;
- если один и тот же текст встречается с разными оценками, ему присваивается самая частая
  для этого текста метка;
- так как положительных отзывов было намного больше, применён undersampling: для каждого
  класса случайно отобрано по 30 000 отзывов;
- для обучения своей CNN-модели авторы обрабатывали тексты инструментом Ekphrasis
  (исправление опечаток, нормализация). Применялась ли эта обработка к опубликованному
  CSV — не указано.

Какую предобработку делал автор модели `blanchefort` при дообучении — не указано.

## Ограничения

- Только одна категория товаров (женская одежда и аксессуары) и, по описанию, один
  интернет-магазин.
- Метки шумные: они получены из оценок в звёздах, а оценка не всегда совпадает
  с тональностью текста.
- Распределение классов искусственно выровнено (по 1/3). Авторы пишут, что реальное
  распределение тональности отзывов им неизвестно.
- Отзывы взяты только с популярных товаров с высоким средним рейтингом.
- Наличие персональных данных в текстах, согласие пользователей и анонимизация — не указано.
- Период сбора данных — не указано. Поддержка и обновление датасета — не указано.

## Использование в проекте

- **Оценка качества.** Отложенную часть RuReviews можно использовать для проверки модели
  (accuracy, macro-F1), так как авторы модели метрики не опубликовали.
- **Базовый набор для дообучения.** Если в сервис будут приходить отзывы о других
  категориях, RuReviews можно дополнить размеченными отзывами из нашего сервиса
  и дообучить модель.
- **Понимание границ модели.** Состав датасета объясняет ограничения модели из
  [Model Card](model-card.md) и риски из раздела [Риски](risks.md).
